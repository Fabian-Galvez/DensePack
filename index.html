DensePack

Created to cut input token cost for frontier AI models

Paste or drop text in. DensePack renders an image of that same text below.

Input

Files are read as raw source, so an HTML file stays HTML source. Nothing leaves your browser. Works fully offline.

Details

Auto automatically generates new images when it reaches 1932x1932 px, before long text causes an image to reach the size that forces downscaling. No manual splitting required.

Fable 5, Opus 5 and Sonnet 5 all downscale images at 2576 px on the long edge and 4784 visual tokens, which causes previously readable images of condensed text to become unpredictable at best and unreadable at worst.


Details

Color coding drastically improves reading accuracy without adding pixels or token cost.


Details

Off: every line break becomes a space. Use this for CSS, JSON, HTML and prose.

On: every line break becomes one visible character, so the reader can put the lines back. Use this for Markdown, YAML and lists, where a line break changes the meaning.

The marker costs nothing. flatten() joins lines with one character either way, a space when it is off and the marker when it is on. On a real 22,700 character report with 172 line breaks, the character count came out identical. The only difference is glyph width: the marker is a few pixels wider than a space, so a line can wrap one character earlier.

Patches are the real vision tokenizer, the same for Fable 5, Opus 5 and Sonnet 5. Checked against the vision docs at platform.claude.com, 20 August 2026. The 2 tokens per image are the content block itself, measured 25 August 2026 on 28 packed PNGs from 418x412 to 1144x1168: the counted figure was the patch count plus exactly 2 at every size.

The Claude Code plugin costs about 145 tokens more per report than this page: a line naming the image files, plus one Read call per image. You paste the image yourself, so this meter adds neither. The plugin's own numbers are in plugin/COSTS.md.
