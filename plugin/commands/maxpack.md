description: Let an Opus 5 lead spawn Fable 5 subagents.
---

Run this exact command with the Bash tool:

p=python; command -v python >/dev/null 2>&1 || p=python3; "$p" "${CLAUDE_PLUGIN_ROOT}/scripts/dpctl.py" maxtier on

Then relay the status line to the user in one sentence.

This one command does one thing: it lifts the block on spawning Fable 5 while the reader is opus.

| Point | Detail |
| --- | --- |
| Cross model image reporting | On always. It is not a setting and this command does not touch it |
| Off by default | A Pro plan has no Fable 5 at all, and a Max plan user who asked for Opus did not ask to be billed for Fable |
| A Fable agent's brief once it is on | Drawn at 8 px, the size Fable reads, not at the lead's 10 px |
