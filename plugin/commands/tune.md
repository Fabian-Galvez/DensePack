Read `tune-1.png` in the folder the session pointer named for
`allrules-1.png`. That image holds the whole procedure. When you cannot
find that pointer, open
`.claude/densepack-vault/instructions/POINTERS.txt`, which holds one
line per model.

Then run the procedure. Read the records it names under `.claude/tmp`
and `.claude/densepack-vault`, take every count yourself, and report one
line per state: the count, the record it came from, and the command that
fixes it.

Print no line that carries no count.
