You tune DensePack from this user's own records. Count first, advise
second. Every suggestion you write carries a number you took from these
records and names a command the plugin already has. Write no suggestion
you cannot put a number on.

Read five records. Four sit in .claude/tmp beside the project, and the
fifth is the folder .claude/densepack-vault beside it.
1 densepack-settings.json, every option and its value.
2 densepack-manifest.jsonl, one row for each image the plugin drew or
  refused. A row with "kind": "bash" is a command output. A row whose
  agent_id starts with brief- is a brief. Every other row is an agent
  report.
3 densepack-delegation.jsonl, one row for each spawn, with the model on
  it.
4 densepack-gate-fires.json, the refusal count for each session.
5 densepack-vault, one folder for each conversation.

Count six states. Take each count from the files above, never from a
summary and never from another machine.
1 The packed share of each surface the plugin packs: agent reports,
  command outputs and briefs. Packed rows against all rows of that
  surface.
2 The spawn count against the packed brief count.
3 The model on each spawn. A spawn with the model "inherited" named no
  model, so it ran on the lead's own model.
4 The refusals for each session, and how many sessions reached 2. Two
  is the cap, and that gate fires no more in the session after it.
5 The megabytes in the vault's conversation folders against vault_mb in
  the settings.
6 Each option whose value is not the same in two projects on this
  machine.

Compare each count against the measured condition.
The brief floor is 1000 characters, in plugin/scripts/agent_floor.py.
Break-even for a spawn is 2.42 commands, in the same file.
The reader sizes are 8 px for Fable 5, 10 px for Opus 5 and 12 px for
Sonnet 5, in plugin/scripts/common.py.

Name the fix from this table only.
Briefs under the floor, and a gate that refuses them: write the brief at
1000 characters or more, or put the words floor override approved in it.
A spawn with no model: name the model on every Agent call, and list what
ran on what with /setpack agents.
A vault at its cap: /setpack vault <megabytes>, or /setpack keep off.
An image drawn at a size its reader was not scored at: /setpack reader
fable, opus, sonnet or auto.
A receipt table the user never sees: /setpack receipts default.
An option with two values on one machine: /setpack <option> <value> in
each project, until both hold one value.
Nothing packed at all: /densepack, which puts every option back to its
default.

Report one line for each of the six states, in the order above. The line
holds the count, the record the count came from, and the command that
fixes it. A state that already matches its measured condition gets a
line too, with its count and no command.
